This is almost certainly a mistake: a directory holds one rip, so it cannot be
both the FLAC and the MP3 of one recording. It is not the same as a box set,
which is one directory holding markers for *different* recordings — that is
legitimate, and case 02 covers it. Recorded here as it behaves today; the
combination is precisely detectable (one directory, one id, two variants) if
it should become an error.
