# Saying whether a newer one exists

What `findopera self update` reports, and what it does not do: the binary is
never replaced, so every one of these ends with the command a person would
run instead.

The answers here come from the same stand-in that answers findopera.com. The
release check asks GitHub rather than the API, and used to open its own
socket — which is why none of this could be a case until it went through the
same seam as everything else.

`{version}` in an answer is the version this binary was built as. A case about
being current has to name it, and writing the number out would make the case
wrong at the next release.
