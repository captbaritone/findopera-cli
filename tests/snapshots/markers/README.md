# Which files name a recording

A folder is claimed by a text file with `findopera-<id>` in its name, and
everything about that rule is here: what counts, what does not, what a word
after the id means, and which folders are never looked in at all.

These read through `organize` with no destination, so what a marker was taken
to mean is the folder name it produced. A file that was not a marker is
simply absent from the listing.
